# VectorDB

A high-performance vector database with the goal of supporting approximate nearest neighbor search over up to 1B embeddings with sub-100ms query latency.

## Features
- Flat, HNSW, and IVF indexes
- SIMD-optimized distance kernels
- Quantized vector storage (FP16 / PQ)
- Single-node, multi-threaded execution
- Reproducible benchmarks
